# PROMPT.md — Рабочая памятка для сессий разработки

## Текущая задача (этап)
Этап 1 (каркас Angular) и этап 2 (контент-модели) — ЗАВЕРШЕНЫ.
Этап 3 (PHP-шлюз + MySQL) — созданы `api/lead.php`, `db/schema.sql`, `.env.example`; локальный PHP/MySQL НЕ установлены.
Далее: локальная установка PHP 8.5.6 + MySQL → формы с UTM → SEO → деплой.

## Контекст (кратко)
- Витрина ИТ-услуг одного исполнителя, две воронки: клиентская и партнёрская.
- Фронт: Angular 22 (standalone, mobile-first), сборка с prerender → чистый HTML.
- Бэк: PHP 8.x — шлюз `api/lead.php` (Яндекс SMTP + MySQL), без мессенджеров.
- Хостинг: виртуальный сервер PHP + MySQL + статика, без Node.

## Обязательные правила
- Не менять контент/модели без согласования с пользователем.
- Заглушки для имени, телефона, фото, кейсов — заполняются позже.
- Письмо при тестах локально НЕ отправлять (`APP_ENV=dev`).
- Секреты (SMTP-пароль, ключи) — только в окружении/конфиге, не в коде и не в git.
- UTM-метки из URL автоматически подставлять в скрытые поля форм.

## Полезные команды
- Сборка (SSR+prerender): `npm run build`
- Статическая сборка (только HTML): `npm run build:static`
- Локальный dev-сервер: `npm start`
- Тесты: `npm test`
- Git: ветка `main`, коммиты после завершения этапа
