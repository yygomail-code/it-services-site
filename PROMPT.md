# PROMPT.md — Рабочая памятка для сессий разработки

## Текущая задача (этап)
Этапы 1–5 ЗАВЕРШЕНЫ:
- Этап 1: каркас Angular — готов
- Этап 2: контент-модели — готов
- Этап 3: PHP-шлюз + MySQL — готов, локальная среда работает
- Этап 4: формы с UTM — готовы
- Этап 5: SEO — базовое готово
- Админка: авторизация (client/manager/admin), лиды, контент, пользователи, настройки — реализована и проверена

Далее: реальный домен, SMTP-проверка, деплой.

## Админка
- URL: http://localhost:4200/admin/login
- По умолчанию: admin / admin123 (смените после первого входа)
- Роли: client (нет доступа), manager (лиды), admin (всё)
- Dev: Angular проксирует /api/* на 127.0.0.1:8090 (proxy.conf.json)
- Контент из БД (site_content) подставляется на сайт автоматически (ContentService.get)

## Локальная среда (Windows)
- **PHP 8.5.10** NTS x64 → `C:\php` (в PATH)
- **MariaDB 11.4.13** (совместима с MySQL) → `C:\mariadb`, данные `C:\mariadb-data`
- БД `it_services` + таблица `leads` — созданы
- Запуск среды: `npm run dev:start` (MariaDB:3306 + PHP:8090), остановка: `npm run dev:stop`
- Шлюз: `POST http://127.0.0.1:8090/api/lead.php`
- Конфиг шлюза: `api/.env` (gitignored), шаблон `api/.env.example`

## Обязательные правила
- Не менять контент/модели без согласования с пользователем.
- Заглушки для имени, телефона, фото, кейсов — заполняются позже.
- Письмо при тестах локально НЕ отправлять (`APP_ENV=dev`).
- Секреты (SMTP-пароль, ключи) — только в окружении/конфиге, не в коде и не в git.
- UTM-метки из URL автоматически подставлять в скрытые поля форм.

## Полезные команды
- Сборка (SSR+prerender): `npm run build`
- Статическая сборка (только HTML): `npm run build:static`
- Локальный dev-сервер Angular: `npm start`
- Тесты: `npm test`
- Локальная среда PHP+MySQL: `npm run dev:start` / `npm run dev:stop`
- PHP: `php -l api/lead.php`, MySQL: `mysql -u root`
